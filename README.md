# GPT-CLI-Assistant

Ein einfaches CLI-Tool für den Chat mit GPT-Modellen (GPT-3.5, GPT-4) auf deinem Computer. Speichert Sitzungen und bietet ein interaktives Einstellungsmenü.

## Features
- Lokale Sitzungsverwaltung
- Markdown-basierte Speicherung
- Anpassbare Zusammenfassungsfunktionen
- Einfaches Einstellungsmenü direkt im Terminal
